## 2. The challenge

**"Turn your solo agent into a teammate."** Build a workflow where an AI agent and the people in a team chat get a real task done together.

The formula on the site: **An AI agent** (one you already use is fine) + **Your team** (in Slack, Teams, Discord or Mattermost) + **Switch** (connects the two) = **A real task, done** (shipped, fixed, reviewed).

Minimum bar (FAQ): a workflow in a team chat where **at least one AI agent and one person** get a real task done together, connected through Switch. You don't need to build a chatbot or a new agent.

## 4. Tracks in detail

### Track 01: Best Business Workflow ($2,000), **our target**
Build a practical workflow using Switch to help people and AI agents get work done. Open to technical and non-technical participants, with **any combination of people, agents and rooms**.

### Track 02: Best Personal or Creative Workflow ($2,000)
Show how you use Switch and AI agents to simplify everyday tasks, manage personal projects, or bring creative ideas to life.

### Track 03: Best Core Contribution ($100 × 20)
Improve Switch's core open-source functionality with a meaningful code contribution: new capabilities, performance, reliability, developer experience. There are issues for integrations and extensions too.

How to get an issue assigned (you can start before Nov 4):
1. Browse open issues labelled `hackathon`: https://github.com/sandbox-quantum/switch/issues?q=is%3Aissue+state%3Aopen+label%3Ahackathon
2. Comment on it, tag **petr-sandbox** on GitHub, and say in a line or two how you plan to solve it.
3. Wait until assigned, then start. Read CONTRIBUTING.md first (dev setup + one-time CLA on first PR).
4. Open the PR and link the issue with `Closes #number`.

Track 03 rules:
- Only `hackathon`-labelled issues count.
- One person per issue. If it's assigned or someone asked first, pick another.
- Max **5 open PRs** at a time, each for an issue assigned to you.
- No spam. Ask only for issues you'll actually do. Spam gets you removed.
- PR for an unassigned issue won't be judged.
- PR must be open by **Nov 7, 11:59 PM IST**.
- Assigned issue with **no activity for 48h** may be reassigned.
- Low-effort PRs (typos, formatting, unreviewed AI output) won't be judged.
- Judged on: the 10 most useful, best-built PRs (site wording; prize text says top 20 × $100).

### Side track: Best Blog (AirPods 5)
Publish a blog post about building with Switch: what you made, how you set it up, what you learned. Can be entered alongside a track or alone. **Judged on clarity, accuracy, and how much it helps a first-time Switch user.**

### Side track: Code with Wispr ($500)
Use **Wispr Flow** to speak your prompts, agent instructions and docs instead of typing them. Best project built by voice wins. Enter alongside any track.
1. Get Wispr Flow via the hackathon link (1 month Pro free): https://wisprflow.ai/?promo_code=WEMAKEDEVS
2. Create an account and dictate as you build: prompts to your coding agent, room instructions, README.
3. When submitting, add your **Wispr usage scorecard**: a screenshot from **Insights** in the Wispr Flow desktop app.

### Side: #HowISwitch
Share your build on social media with **#HowISwitch**. Top 5 posts each get a Logitech mechanical keyboard.

## 7. FAQ (paraphrased in full)

- **Docs/resources?** All on the Resources tab (section 9 below). If you open one link, open the quickstart (an agent answering in a chat channel in about 10 min).
- **When?** Nov 4 12:01 AM IST to Nov 7 11:59 PM IST.
- **Who can join?** Anyone, anywhere, free, solo or team of up to 4.
- **What to build?** A team-chat workflow where at least one AI agent and one person get a real task done, connected through Switch. No need to build a new agent.
- **Is Switch mandatory?** **Yes.** It must be central, and **the README should show how you used it.**
- **Cost?** Switch is free and open source, self-hostable on your laptop. You need a subscription or API key for your own agent.
- **What do I need?** Switch Console (desktop app), Docker, and an AI coding agent (Claude Code, Codex, OpenCode). Console runs on macOS; Windows/Linux in early access.
- **Need Slack admin?** No. Local Switch ships **Mattermost** (free chat app), so you can build and record without a company workspace. Slack/Teams/Discord/Telegram can be connected any time.
- **Which agents?** Any. Claude Code, Codex, OpenCode work out of the box through Console. Custom agents (LangChain, Google ADK, OpenAI, anything) join via the agent protocol.
- **Bring an existing agent?** Yes, encouraged. Existing agents, libraries and templates are fine. **The Switch setup and the workflow your agents run must be built during the hackathon.**
- **AI coding tools?** Yes, but **you must understand what you submit and be able to explain how it works.**
- **Multiple tracks?** Yes: a workflow + PRs to core + blog in the same hackathon. Wispr and Blog stack on any track.
- **Help?** WeMakeDevs Discord; Switch, WeMakeDevs and DevTools Academy teams are there all event.
